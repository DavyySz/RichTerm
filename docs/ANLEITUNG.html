1. Was RichTerm ist

RichTerm ist ein Fenster mit zwei Arten von Tabs:

  • Chat: Du schreibst unten, die KI antwortet oben. Die Antworten werden gerendert wie in einem Browser-Chat: Markdown, LaTeX-Formeln in Buchqualität, Tabellen, Mermaid-Diagramme, Bilder und HTML-Blöcke als Live-Vorschau (Animationen, interaktive Grafiken).
  • Terminal: ein vollwertiges Terminal (dieselbe Engine wie GNOME Terminal), beliebig viele Tabs.

Die KI arbeitet in einem Arbeitsordner. Mit Claude Code als Backend kann sie die Dateien darin lesen, Code ausführen und Dateien schreiben, etwa Vorlesungsfolien lesen und dazu Fragen beantworten. In jedem Ordner liegen zwei Dateien, die RichTerm selbst anlegt: richterm.md (das Profil: Rolle, Verhalten, Modell) und richterm-verlauf.md (das Gedächtnis).

Es ist nichts installiert worden: RichTerm besteht aus Python und den Bibliotheken, die Linux Mint ohnehin mitbringt. Das Projekt liegt unter ~/Desktop/RichTerm und ist ein Git-Repository.

2. Starten

Im aktuellen Ordner (der übliche Weg)

cd ~/Uni/Maschinelles_Lernen     # Ordner mit Folien, Übungen, Notizen
richterm                        # RichTerm öffnet sich mit diesem Ordner

Das Terminal ist sofort wieder frei und darf geschlossen werden. Mit Pfad geht es von überall: richterm ~/Uni/ML. Jeder Aufruf öffnet ein eigenes Fenster; du kannst also ein RichTerm für die Vorlesung und eins für ein Projekt gleichzeitig offen haben.

Weitere Wege

  • Dateimanager (Nemo): Rechtsklick auf einen Ordner oder in einen Ordner hinein, „RichTerm hier öffnen“.
  • Desktop-Icon / Anwendungsmenü: startet im Home-Ordner; den Ordner wechselst du danach über den Ordnerknopf oben links.
Beim ersten Start in einem Ordner werden richterm.md und richterm-verlauf.md angelegt. Die Statuszeile unter dem Eingabefeld weist darauf hin. Fülle das Profil aus (Abschnitt 4), bevor du ernsthaft arbeitest.

In den Antworten

  • Graue Zeilen sind Werkzeugaufrufe (Datei gelesen, Befehl ausgeführt). Ein Klick zeigt Details und das Ergebnis.
  • Live-Vorschau bei HTML-Blöcken: Code zeigt den Quelltext, Neu laden startet die Animation neu, Im Browser öffnet die Seite groß.
  • Berechtigungsfrage: ein Kasten mit Erlauben / Ablehnen, wenn die KI ein Werkzeug benutzen will, das nicht freigegeben ist.
  • Ctrl++ / − ändert die Schriftgröße des Chats.

4. Das Profil: richterm.md

Das Profil ist die wichtigste Datei. Es wird bei jedem Start gelesen und der KI als verbindliche Anweisung mitgegeben, egal ob Claude oder eine lokale KI antwortet. Es gilt nur für diesen Ordner. So verhält sich die KI im Vorlesungsordner wie ein Tutor und im Projektordner wie ein Entwickler.

Oben: Einstellungen

FeldWerteBedeutung
backend, modelwerden vom Modellmenü gesetztNicht von Hand nötig. claude = Claude Code mit Dateizugriff; command = andere KI, nur Chat.
commandz. B. ollama run {model}Nur für command. {model} wird ersetzt.
permissionsdefault · acceptEdits · bypassPermissionsdefault = Kopfzeile entscheidet; sonst festgelegt und gesperrt.
allowed_toolsz. B. Read Grep GlobNur diese Werkzeuge: hier reines Lesen, nichts wird geändert.
disallowed_toolsz. B. WebSearch "Bash(rm *)"Diese Werkzeuge verbieten.
languagez. B. DeutschSprache der Antworten.
historytrue · falseGedächtnis (Verlaufsdatei) an oder aus.
context_charsZahl, Standard 20000Wie viel Verlauf beim Start mitgegeben wird. Claude: 20000–60000; kleine lokale Modelle: 4000–8000.

Darunter: Anweisungen in normaler Sprache

Die Vorlage enthält sieben Abschnitte mit Beispielen. Schreib sie einfach um, lösche, was nicht passt:

  • Rolle: Tutor, Entwickler, Reviewer, Prüfungsvorbereiter, Schreibassistent …
  • Themengebiet und Ziel: „Vorlesung ML, Klausur im Februar, Schwerpunkt neuronale Netze.“
  • Was in diesem Ordner liegt: „folien/ = PDFs, uebungen/ = Übungsblätter, notizen.md = meine Notizen.“
  • Verhalten: schrittweise erklären, Rückfragen stellen, Quellen aus dem Ordner nennen.
  • Genauigkeit und Kreativität: keine erfundenen Fakten; „steht in den Unterlagen“ vs. „Einschätzung“ trennen.
  • Antwortformat: LaTeX-Formeln, nummerierte Herleitungen, Diagramme, Länge.
  • Nicht erlaubt: nichts löschen, Folien nur lesen …
Nach jeder Änderung: im Chat auf Neu laden klicken. Die Änderung gilt ab der nächsten Nachricht (es wird eine neue Sitzung gestartet; der Verlauf bleibt erhalten).

5. Modelle wählen und laden

Oben im Chat gibt es das Modellmenü. Dort stehen alle Claude-Modelle und alle lokalen Modelle, die auf deinem Rechner liegen. Auswählen, fertig. Die Wahl gilt für diesen Ordner und ab der nächsten Nachricht; RichTerm trägt sie selbst in richterm.md ein. Du musst keine Datei bearbeiten.

MenüeintragWas es ist
Claude (Standard) / Opus / Sonnet / HaikuClaude Code. Liest deine Dateien, führt Code aus, schreibt Dateien. Opus = am stärksten, Sonnet = ausgewogen, Haiku = schnell und günstig. Kosten pro Antwort stehen in der Statuszeile.
Lokal (Ollama): z. B. qwen2.5:7b (4.7 GB)Läuft komplett auf deinem Rechner: kostenlos, nichts verlässt den PC. Kann keine Dateien lesen, nur chatten. Langsamer und einfacher als Claude.
Lokales Modell herunterladen …Ein Feld erscheint: Modellnamen eintippen (z. B. qwen2.5:7b), Laden klicken. Der Fortschritt steht in der Statuszeile; danach ist das Modell im Menü und ausgewählt.

Ein neues lokales Modell holen, Schritt für Schritt

  1. Im Modellmenü „Lokales Modell herunterladen …“ wählen.
  2. Namen eintippen, z. B. qwen2.5:7b, und auf Laden klicken. Namen findest du auf ollama.com/library.
  3. Warten (4,7 GB dauern ein paar Minuten; die Statuszeile zeigt Prozent). Das Modell ist danach automatisch ausgewählt.
  4. Frage stellen.

Zurück zu Claude: im Menü wieder ein Claude-Modell wählen.

Lokales ModellGrößeEignung auf deinem Laptop (CPU, 31 GB RAM)
qwen2.5:0.5b0,4 GBNur zum Testen; antwortet in Sekunden, ignoriert Kontext oft.
qwen2.5:3b1,9 GBSchnell, einfaches Niveau.
qwen2.5:7b4,7 GBBeste Mischung aus Deutsch, Mathe und Code; 4–8 Wörter/s.
llama3.1:8b4,9 GBSolide Allzweck-Wahl.
qwen2.5:14b9 GBBesser, aber nur 1–3 Wörter/s.
Hintergrund (musst du nicht wissen): RichTerm bringt ein eigenes Ollama mit (unter ~/.local/share/ollama, Port 11435) und startet es bei Bedarf selbst. Im RichTerm-Terminal geht auch die Kommandozeile: ollama list, ollama pull name, ollama rm name. Andere KIs mit Kommandozeile lassen sich im Profil über backend: command und command: … anbinden.

6. Gedächtnis und Sitzungen

Es gibt zwei Ebenen, die zusammenarbeiten:

Claude-Code-Sitzung

Claude Code speichert jedes Gespräch selbst (unter ~/.claude/projects/…), mit allem, was es gelesen und getan hat. RichTerm merkt sich pro Ordner die letzte Sitzung und setzt sie beim nächsten Start automatisch fort (Statuszeile: „Letzte Claude-Sitzung wird fortgesetzt“). Neuer Chat beendet das und beginnt frisch.

Die Verlaufsdatei richterm-verlauf.md

Das modellunabhängige Gedächtnis im Ordner. Jede Frage und Antwort wird angehängt, mit Zeit, Modell und LaTeX-Formeln. Beim Start einer neuen Sitzung, also nach einem Modell- oder Backend-Wechsel oder nach Neuer Chat, bekommt die KI die Zusammenfassung oben in der Datei und den jüngsten Verlauf mit. Nur darüber weiß Sonnet, was du mit Haiku besprochen hast, oder ein lokales Modell, was Claude erklärt hat. Beim Start zeigt der Chat die letzten Einträge grau an.

Automatische Verdichtung: Wird der Rohverlauf länger als das Budget (context_chars), fasst das Modell den älteren Teil zur Zusammenfassung zusammen. Das Original wandert nach richterm-verlauf.archiv.md; nichts geht verloren.

Beide Dateien darfst du bearbeiten: die Zusammenfassung kürzen, Wichtiges ergänzen, Falsches streichen. history: false im Profil schaltet das Gedächtnis ab.

7. Berechtigungen

Mit Claude Code kann die KI Werkzeuge benutzen: Dateien lesen und schreiben, Befehle ausführen, im Web suchen. Was ohne Nachfrage erlaubt ist, steuert der Berechtigungsmodus:

ModusVerhaltenWann sinnvoll
Fragen (default)Lesen geht sofort; Schreiben und Befehle werden im Chat erfragt (Erlauben / Ablehnen).Lernen, Unterlagen lesen, alles, wo nichts verändert werden soll.
Dateien bearbeiten erlauben (acceptEdits)Dateien ändern ohne Nachfrage; Befehle werden weiter erfragt.Programmieren im Projektordner.
Alles erlauben (bypassPermissions)Keine Nachfragen.Nur in Ordnern, in denen nichts kaputtgehen kann.

Feiner geht es mit allowed_tools / disallowed_tools im Profil, etwa allowed_tools: Read Grep Glob für einen Ordner, der nur gelesen werden darf.

8. Das Terminal und der Befehl rt

Ctrl+Shift+T öffnet ein Terminal im Arbeitsordner. Darin sind rt, ollama und claude direkt verfügbar. Mit rt schickst du Inhalte aus dem Terminal in den Chat:

rt ask 'Erkläre mir Backpropagation'    # Frage an den Chat
rt latex '\frac{1}{1+e^{-z}}'           # Formel als Karte im Chat
rt md notizen.md                        # Markdown-Datei (mit $…$-Formeln) anzeigen
rt image plot.png                       # Bild anzeigen (auch GIF)
rt html seite.html                      # HTML-Seite mit Animation einbetten
rt mermaid 'graph LR; A-->B'            # Diagramm
rt clear                                # Chat-Karten entfernen
rt --help                               # alle Möglichkeiten

rt funktioniert auch in jedem anderen Terminal, solange RichTerm läuft. Startest du claude in einem RichTerm-Terminal, weiß es durch ~/.claude/CLAUDE.md, dass es Formeln und Bilder mit rt in den Chat-Tab schicken kann.

10. Typische Arbeitsabläufe

Lernen mit Vorlesungsfolien

  1. Ordner anlegen, z. B. ~/Uni/ML mit Unterordnern folien/, uebungen/.
  2. cd ~/Uni/ML und richterm.
  3. Profil klicken: Rolle „Tutor“, Thema, Ordnerstruktur, „Quellen nennen“, Berechtigungen auf Fragen lassen. Neu laden.
  4. Fragen: „Fass Folie 10–15 aus vorlesung_03.pdf zusammen und leite die Formel her.“ Claude liest das PDF und antwortet mit Formeln.
  5. Am nächsten Tag wieder richterm: Die Sitzung wird fortgesetzt, der Verlauf steht im Chat.

Programmieren

  1. richterm ~/Projekte/mein-projekt.
  2. Profil: Rolle „Entwickler“, permissions: acceptEdits, ggf. Verbote (nichts löschen, keine Git-Pushes).
  3. Aufgaben stellen; Werkzeugaufrufe erscheinen als graue Zeilen, Klick zeigt Details.

Kostenlos und privat mit lokalem Modell

  1. Modellmenü → „Lokales Modell herunterladen …“ → qwen2.5:7b → Laden (einmalig).
  2. Das Modell ist danach ausgewählt; sonst im Menü wählen.
  3. Fragen stellen; Antworten dauern länger und sind einfacher, aber nichts verlässt den Rechner.

11. Probleme und Lösungen

ProblemLösung
Desktop-Icon tut nichtsRechtsklick auf das Icon, „Starten erlauben“. Oder im Terminal richterm.
„Der Befehl claude wurde nicht gefunden“Claude Code ist nicht installiert oder nicht im PATH. Im Terminal claude --version prüfen.
Lokales Modell antwortet nicht oder ewigIm RichTerm-Terminal ollama list und ollama ps prüfen. Läuft ein alter System-Ollama auf 11434, stört er nicht; RichTerm benutzt Port 11435. Notfalls pkill -f "ollama serve" für den eigenen Dienst; er startet beim nächsten Mal neu.
Antwort wird abgeschnitten / Prozess beendetStatuszeile lesen; Neuer Chat starten. Der Verlauf bleibt in richterm-verlauf.md.
Profiländerung wirkt nichtNeu laden klicken; gilt ab der nächsten Nachricht. Prüfen, ob das Feld oben (Einstellungen) oder unten (Text) gemeint ist.
Berechtigungen in der Kopfzeile gesperrtDas Profil legt sie fest (permissions:). Dort default eintragen, dann entscheidet die Kopfzeile. Bei lokalen Modellen gibt es keine Berechtigungen, weil sie keine Werkzeuge haben.
Formeln werden nicht gerendertDie KI muss LaTeX mit $…$ schreiben; das steht im Profil. Bei lokalen Modellen hilft ein Hinweis in der Frage.
Kosten im Blick behaltenDie Statuszeile zeigt Dauer und Kosten jeder Antwort. Haiku ist am günstigsten.
